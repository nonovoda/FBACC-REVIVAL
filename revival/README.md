# FBACC Revival — Phase 1 Shell

Этот модуль — следующий практический шаг после Phase 0.

## Что делает
- Поднимает изолированную модалку (`FBACCRevivalShell.init()`);
- Даёт read-only вкладки: `Аккаунт`, `BM`, `FP`;
- Строит snapshot контекста из URL/cookie/hash без write-действий;
- Ведёт системный лог.

## Зачем
- Подготовить стабильный контейнер для миграции блоков статуса из legacy;
- Сохранить безопасный режим: только чтение, без мутаций.

## Запуск
В консоли на странице:
```js
FBACCRevivalShell.init();
```

# FBACC Revival — Phase 0 Shell

Этот модуль — первый практический шаг рефакторинга legacy `fbacc.js`.

## Что делает
- Поднимает изолированную модалку (`FBACCRevivalShell.init()`);
- Использует стили из `styles.css` и `typography.css`;
- Даёт базовый системный лог;
- Даёт минимальный health-check без изменения бизнес-логики.

## Зачем
- Зафиксировать новый UI-контейнер до миграции функциональных модулей;
- Создать точку входа для следующих фаз (`status`, `safe writes`, `bulk`).

## Запуск
В консоли на странице:
```js
FBACCRevivalShell.init();
```
